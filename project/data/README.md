## Cara menyiapkan data
1. Unduh zip dari halaman UCI di atas, simpan ke `project/data/raw/` dengan nama `ai4i+2020+predictive+maintenance+dataset.zip`. (Salinan arsip pemilik repo ada di repositori dataset pribadi, folder `ai4i-2020-predictive-maintenance`.)
2. Jalankan skrip dari folder `project/` (lihat README utama). Skrip memverifikasi SHA-256 sebelum membaca data.

Data mentah tidak di-commit ke repository ini.
